# 台股財報分析（手機版）

輸入台股公司名稱或代號，自動抓取近五年年度財報，產生
**經營分析 / 獲利分析 / 財務健全度** 三維互動儀表板。

## 使用

雙擊 `啟動.bat`（或在資料夾內執行 `python server.py`），瀏覽器會自動開啟：

```bash
python server.py
```

- 電腦：<http://localhost:8899>
- **手機**：與電腦連同一個 Wi-Fi，開啟啟動時終端機顯示的 `http://<電腦IP>:8899`
  （第一次連線 Windows 防火牆可能會詢問，允許「私人網路」即可）

在首頁輸入「台積電」或「2330」→ 邊打邊出現候選 → 點選即開始分析。
首次分析單一檔約 10–25 秒（要打三支 API＋三次 MOPS），結果快取 12 小時，之後秒開。

右上角 `⤓` 可下載**單檔 HTML 報告**，內含全部數據與圖表，可離線瀏覽或直接分享。

## 三個分頁的內容

| 分頁 | KPI 卡 | 圖表 | 資料表 |
|---|---|---|---|
| 📊 經營 | 營收、毛利率、營益率、費用率、研發費用率 | 營收+毛利率、費用結構堆疊、費用率趨勢、營業利益+利益率 | 損益表明細＋趨勢評估 |
| 💰 獲利 | 淨利、EPS、ROE、ROA、三層利潤率 | 淨利+淨利率、EPS、三層利潤率、現金股利+配息率 | 獲利能力彙總＋趨勢評估 |
| 🏦 健全度 | 流動比率、負債比率、現金部位、營業CF、自由現金流 | 資產負債結構、現金流三表、流動+負債比率、現金部位 | 資產負債與現金流＋趨勢評估 |

每頁另有「🔍 亮點」區塊，由數據自動生成 4–5 條含具體數字的觀察。

## 資料來源

| 來源 | 取得內容 |
|---|---|
| [FinMind](https://finmindtrade.com/) 開放 API | 損益表（單季，程式加總為年度）、資產負債表、現金流量表（年度累計）、現金股利 |
| [MOPS 公開資訊觀測站](https://mopsov.twse.com.tw/) `t164sb04` | 推銷／管理／研究發展費用明細（FinMind 只有營業費用合計） |
| TWSE / TPEx OpenAPI | 上市櫃公司代號與名稱對照（供搜尋，快取 7 天） |

## 內建驗證

- **資料血緣**：每份報告標注抓取時間、來源，並附 MOPS 原始申報與 FinMind 原始資料連結
- **合理性檢查**：毛利率 >100%／<-50%、流動比率為負、負債比率 >100%、ROE >100%、
  相鄰年度淨利率波動 >30pp，皆會在頁首以警示條列出
- **行業判別**：金融、保險等無「營業毛利」「流動／非流動」分類的公司，
  自動隱藏不適用的指標卡並加註說明

## 傳給別人用（純前端版）

`python build_static.py` 會產生 **`dist/台股財報分析.html`** — 一個 98 KB 的獨立檔案，
內含 1,979 家上市櫃公司清單與全部分析邏輯，**不需要任何伺服器**：
財報由對方的瀏覽器直接向 FinMind 取得（該 API 回應 `Access-Control-Allow-Origin: *`），
指標與文案在對方裝置上即時計算，任何個股、隨時可查。

兩種給法：

1. **放靜態主機拿一條網址**（推薦，手機最順）
   把 `dist/index.html` 丟到 GitHub Pages / Netlify Drop / Cloudflare Pages，
   得到網址後直接傳連結。網址支援 `#2330` 這種錨點，可以直接分享到「某一檔的分析」。
2. **直接傳檔案**：把 `台股財報分析.html` 用 LINE／email／隨身碟給對方，
   雙擊用瀏覽器開即可（FinMind 對 `file://` 的 null origin 也放行）。

### 與本機版（server.py）的差異

| | 純前端版 `dist/` | 本機版 `server.py` |
|---|---|---|
| 需要伺服器 | 否 | 是（Python） |
| 給別人用 | 傳連結或傳檔即可 | 對方要自己裝 Python 跑 |
| 推銷／管理／研發拆分 | ✗（MOPS 無 CORS，只有營業費用合計） | ✓ |
| 圖表 | 成本費用結構、毛利率 vs 費用率 | 管銷研發堆疊、四條費用率 |
| 快取 | 瀏覽器分頁內（重整即重抓） | 檔案快取 12 小時 |

其餘 KPI、亮點、表格趨勢評估、合理性檢查完全相同，數字兩版一致
（台積電 2025：營收 38,091 億、毛利率 59.9%、營益率 50.8%）。

## 檔案

```
server.py        本機 HTTP 伺服器＋API＋快取（純標準函式庫）
build_static.py  產生可分享的單檔純前端版 → dist/
static/          純前端版模板（分析引擎的 JavaScript 版本）
analyzer.py      年度序列 → 衍生指標 → KPI/亮點/表格文案 → 合理性檢查
datasource.py    FinMind / MOPS / 股票清單 抓取層
web/             index.html · style.css · app.js（手機優先，含深色模式）
cache/           股票清單與分析結果快取（可安全刪除）
```

相依套件：`requests`、`beautifulsoup4`（圖表用 Chart.js CDN，需連網）。
